# SiftingIO

Market data API platform providing real-time and historical data for stocks, FX, crypto, commodities, DEX, and on-chain markets through REST, WebSocket, and FIX APIs. Notably agent-forward with a hosted MCP server, llms.txt, and published agent skills.

## APIs

- **SiftingIO Market Data API** — REST API for historical OHLCV, live market data, currency conversion, discovery, SEC filings, filing text/analysis, XBRL financials, insiders & holdings, economic calendar, market hours, technical signals, and DEX wallets. Version-pinned under /v1. (`https://api.sifting.io`)
- **SiftingIO Live Stream** — WebSocket streaming API for live market data, described by an AsyncAPI 3.0 contract. Also offers a documented FIX API. (`wss://stream.sifting.io/ws/v1`)
- **SiftingIO MCP Server** — Hosted remote MCP server (Streamable HTTP) exposing tools for live prices, historical bars, discovery, fundamentals, filings, market status, and the economic calendar. Auth via X-API-Key or Bearer. (`https://mcp.sifting.io/mcp`)

> Hosted remote MCP server at https://mcp.sifting.io/mcp; a local bridge via 'npx mcp-remote' is documented for clients lacking native remote support (local bridge not cataloged as MCPServer). Official SDKs in Go, Python, TypeScript. Additional integrations: n8n community node, Supabase FDW, Grafana datasource, MetaTrader/FIX. No GraphQL surface. Free no-card tier makes all interfaces immediately consumable with an sft_... API key.
