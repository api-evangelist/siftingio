# SiftingIO

Cross-asset market data APIs covering stocks, forex, cryptocurrency, DeFi/on-chain, commodities, and SEC fundamentals. Delivered via REST, WebSocket, and FIX with a public OpenAPI 3.1 contract and an open-source (local) MCP server.

- **Provider:** https://sifting.io

## APIs

- **SiftingIO Market Data API** — REST market data API (v1) covering historical OHLCV, live data, currency conversion, discovery, SEC filings, XBRL financials, insiders/holdings, economic calendar, market hours, technical signals, and DEX wallets. Auth via X-API-Key header or api_key query param. WebSocket streaming at wss://stream.sifting.io/ws/v1 and FIX also available. (`https://api.sifting.io`)

> REST base https://api.sifting.io (version pinned in path, currently /v1); WebSocket base wss://stream.sifting.io/ws/v1; FIX also offered. OpenAPI 3.1.0 confirmed valid (37 paths, apiKey auth via ApiKeyHeader X-API-Key and ApiKeyQuery api_key). The MCP server (github.com/SiftingIO/siftingio-mcp, npm siftingio-mcp) is LOCAL/self-hosted only — stdio via 'npx -y siftingio-mcp', or an optional Streamable HTTP transport bound to loopback (http://127.0.0.1:3000/mcp) that rejects non-local origins; there is NO provider-hosted remote MCP endpoint, so it is not cataloged as an MCPServer property. llms.txt is declared/advertised at https://sifting.io/llms.txt but its body could not be rendered during research. The advertised apis.json at https://sifting.io/apis.json returned 'not accessible' at fetch time. No AsyncAPI, GraphQL, or Postman collection published; WebSocket/FIX documented in prose only.
